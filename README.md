# 身份证图片处理器

交互式身份证照片处理工具：加载图片 → 自动检测角点 → 拖动微调 → 一键导出。

## 使用方式

```bash
make build       # 构建
make dev         # 开发模式（热重载）
```

构建产物：`build/bin/idcard-processor`

## 功能

- 自动检测身份证轮廓，生成初始角点框
- 拖动四个控制点精确标注身份证四角，连线框实时渲染
- 透视变换修正倾斜，缩放至标准画幅
- 保留圆角，外部填充白色
- 输出标准比例 85.6mm × 54.0mm，可调 DPI（默认 350）

## 处理流程

```
自动检测角点 → 用户拖动微调
→ 透视变换（高斯消元 8×8）→ 双线性插值
→ 圆角遮罩 → 保存
```

## 技术特点

- Go + React（Wails v2 桌面应用）
- 透视变换矩阵高斯全选主元消元法求解
- Andrew 单调链算法计算凸包，道格拉斯-普克算法简化多边形
- Otsu 自适应二值化，Canny 边缘检测，滞后阈值边缘连接
- 四级降级角点检测：Canny → 亮度分割 → 反亮度分割 → 模板定位

## 构建环境

- Go 1.21+
- Wails v2.13（Linux 需 webkit2gtk 4.1，构建加 `-tags webkit2_41`）
- Node.js 22+
